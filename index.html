COMMON QUESTIONS

Quick answers.

How do I register for an event?

Open Discover, select an event and press Register. Complete the form to save your registration.

Where can I find my registrations?

Open My registrations in the navigation. Saved entries are stored in this browser.

Does the website work on mobile?

Yes. The layout and navigation adapt to mobile, tablet and desktop screens.

Are these official tickets?

No. This is a front-end student project with sample event data. It does not issue official tickets or contact event organisers.
